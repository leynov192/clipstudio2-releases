## 2. Назначение и цели создания сайта

**Назначение.** Сайт показывает ассортимент магазина: категории товаров, цены и
характеристики. По нему покупатель может выбрать товар до визита в магазин или до звонка.

**Целевая аудитория.**
- Покупатели от 16 до 55 лет, которые выбирают смартфон, ноутбук или аудиотехнику.
- Студенты и школьники, которые ищут недорогую технику для учёбы.
- Посетители заходят и с компьютера, и с телефона (примерно поровну).

**Проблема пользователя.** Покупатель не знает, что есть в магазине и сколько это
стоит. Чтобы сравнить модели, ему приходится звонить или идти в магазин.

**Главное действие пользователя.** Найти товар нужной категории в каталоге, открыть
его карточку с ценой и характеристиками и связаться с магазином (позвонить по номеру из
шапки или подвала).

## 4. Требования к функциональности

### Т1. Работающая навигация
В шапке каждой страницы есть меню из трёх ссылок: «Главная» (`index.html`),
«Каталог» (`catalog.html`), «Товар дня» (`detail.html`).

**Критерий приёмки:** на каждой из 3 страниц каждая из 3 ссылок меню открывает
нужную страницу (3 × 3 = 9 переходов без ошибок). Ссылка текущей страницы имеет
атрибут `aria-current="page"` и подчёркнута линией толщиной 3 px. Логотип ведёт на
главную.

### Т2. Корректное отображение карточек
**Критерий приёмки:** в каталоге при показе всех категорий выводится ровно 6 карточек.
Каждая карточка содержит изображение, метку категории, название, краткое описание,
цену и ссылку «Подробнее». У всех карточек в ряду одинаковая высота. Изображения
имеют пропорции 4:3 и не искажаются (`object-fit: contain`). На главной выводятся
3 карточки хитов продаж.

### Т3. Открытие подробной информации и возврат
**Критерий приёмки:** по ссылке «Подробнее» в любой карточке открывается
`detail.html?id=<id товара>`. Заголовок `h1` совпадает с названием товара в карточке,
цена совпадает с ценой в карточке. Таблица характеристик содержит не менее
4 строк. Ссылка «← Вернуться в каталог» открывает `catalog.html`. Если `id` не
указан, показывается «Товар дня» (Nova X5). Если `id` неизвестен, показывается
сообщение «Товар не найден» и ссылка на каталог.

### Т4. Адаптация для телефона
**Критерий приёмки:**
- при ширине окна **360 px** карточки идут в одну колонку, текст и изображения
  не выходят за экран, горизонтальной прокрутки нет (ширина документа ≤ ширины окна);
- при **768 px** карточки идут в 2 колонки, горизонтальной прокрутки нет;
- при **1440 px** карточки идут в 3 колонки, ширина контента ≤ 1200 px, горизонтальной прокрутки нет;
- при ширине < 640 px меню переносится под логотип и выводится одной строкой
  из 3 ссылок, все ссылки видны без дополнительных кнопок;
- размер основного текста на телефоне не меньше 16 px.

### Т5. Управление ссылками с клавиатуры
**Критерий приёмки:** все ссылки и кнопки доступны клавишей Tab в порядке их
следования на экране (сверху вниз, слева направо). У элемента в фокусе видна
рамка `outline` толщиной 3 px контрастного цвета. Клавиша Enter на ссылке
выполняет переход, на кнопке фильтра — применяет фильтр. Первым по Tab идёт
ссылка «Перейти к содержимому», которая переносит фокус на `main`.

### Т6. Фильтр по категориям в каталоге
Над карточками расположены 4 кнопки: «Все», «Смартфоны», «Ноутбуки», «Аудио».

**Критерий приёмки:** после нажатия «Ноутбуки» видны только 2 карточки
категории «Ноутбуки», у нажатой кнопки `aria-pressed="true"`, счётчик показывает
«Показано товаров: 2». Кнопка «Все» возвращает 6 карточек. Ссылка категории на главной
(`catalog.html?cat=laptops` и т. п.) открывает каталог с уже включённым фильтром.
Если JavaScript отключён, видны все 6 карточек.

### Т7. Изображения
**Критерий приёмки:** все изображения на 3 страницах загружаются (у каждого
`naturalWidth > 0`). У каждого содержательного изображения есть непустой атрибут `alt`
с описанием товара. У декоративных изображений `alt=""`.

### Т8. Семантика и заголовки
**Критерий приёмки:** на каждой странице есть элементы `header`, `nav`, `main`,
`footer`, ровно один `h1` и уникальный `title` вида «Название страницы — ВольтМаркет, магазин электроники».

## 5. Требования к дизайну

Подробно описаны в [design.md](design.md): шрифт, палитра, размеры заголовков,
отступы, сетка. Кратко:
- шрифт: системный без засечек (`"Segoe UI", Roboto, Arial, sans-serif`), основной текст 16 px;
- цвета: основной `#1E4FD8`, тёмный `#14213D`, акцент `#FFB703`, фон `#F4F6FB`;
- сетка карточек: 3 / 2 / 1 колонки (≥ 1024 / 640–1023 / < 640 px), промежуток 24 px;
- максимальная ширина контента 1200 px, внутренние отступы контейнера 16 px на телефоне и 24 px на компьютере.

## 6. Ограничения

- В проекте нет корзины, оплаты, личного кабинета и формы заказа. Покупатель
  связывается с магазином по телефону. Формы и поиск не заявлены, поэтому не реализуются.
- Сайт работает без сервера: страницы открываются из файловой системы или с GitHub Pages.
- Поддерживаемые браузеры: последние версии Chrome, Firefox, Edge и Safari.
